# Implement 环境准备

进入 implement 前，确认项目所需的 QCP、Rocq MCP 和编译环境已配置可用，之后按 QCP agent
（当前 QCP 仓库 `AGENTS.md` 指定的 workflow/controller）完成证明；不另设一套证明前验收流程。

首次配置或更换环境时，确保需要从源码构建的工具已构建成功、预编译工具可运行，
编译器、交互后端与项目依赖兼容。通过实际项目导入和一次交互目标推进确认环境可用，
这些检查可以结合 QCP agent 的正常操作完成。

同一环境继续工作时复用已有配置与成功结果，不要求每次新建诊断 lemma、遍历交互接口、
重跑 QCP 样例或全量构建依赖。依赖按需增量构建；工具、依赖或路径变化时只检查受影响部分。

若构建、库加载或交互后端出错，先修复环境再继续受影响的证明，不静默改用批量编译替代
要求的 MCP 交互证明。修改 MCP 启动配置后须重启对应连接，并确认当前连接已使用新环境。

证明步骤、工具调用、产物检查和完成条件遵循 QCP agent 的流程。
